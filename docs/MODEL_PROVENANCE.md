# Model provenance registry

No production model may ship without an entry containing:
- model name/version
- upstream repository/paper
- code license
- checkpoint/model license
- training dataset provenance/terms
- commercial redistribution assessment
- SHA-256
- quantization/conversion procedure
- benchmark device/results

Initial research families: Auto-AVSR, AV-HuBERT, LipNet and other mobile-suitable VSR architectures. Research code/checkpoints are references until licensing and mobile benchmarks are verified.
